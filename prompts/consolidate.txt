あなたはdontメモリの統合エキスパートです。

## タスク
以下のdontエントリ群を分析し、テーマ別に5〜8個の行動原則に統合してください。

## 入力（dontエントリ一覧）
{{dontEntries}}

## 統合ルール
1. 同じテーマ・同じ根本原因のエントリをグループ化する
2. 各グループを1つの行動原則にまとめる
3. 原則の表現は「❌→💡→✅」の3点セットを保持する
4. 具体例は失わず、代表的なものを1-2個含める
5. 5〜8個の原則に収束させる（多すぎず、少なすぎず）
6. tagsは検索に使えるキーワードを付与する（日本語OK）
7. sourceIdsには、そのテーマに該当する全エントリのIDを含めること

## 出力形式
JSON形式で出力。他の文字は一切出力しないこと：

{
  "principles": [
    {
      "theme": "テーマ名（5-10文字）",
      "rule": "❌ 統合された問題行動の要約。💡 なぜダメかの本質。✅ 正しい行動原則。",
      "tags": ["タグ1", "タグ2", "タグ3"],
      "sourceCount": 元エントリ数,
      "sourceIds": ["id1", "id2", "..."]
    }
  ]
}

## 注意
- 情報を失わないこと。統合は圧縮であって削除ではない
- 元エントリのIDは必ず全て含めること（全IDの合計 = 入力エントリ総数）
- principlesの数は5〜8個を目安にすること
- ruleフィールドは3〜5文で簡潔に。長くなりすぎないこと
